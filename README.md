# GestorApps

**A modern, lightweight and privacy-focused Android application manager.**

GestorApps is an Android application designed to help users explore, search and manage the applications installed on their devices through a clean and intuitive interface.

## ✨ Features

- 📱 **Installed apps:** View applications installed on your device.
- 🔍 **Instant search:** Find apps by name or package name.
- 🗂️ **App filters:** Separate user applications from system applications.
- ↕️ **Sorting:** Organize applications alphabetically (A–Z / Z–A).
- 📋 **App information:** View package names, versions and app types.
- 🚀 **Launch apps:** Open installed applications directly.
- ⚙️ **App settings:** Access Android settings for each application.
- 🗑️ **Uninstall:** Start the official Android uninstall process.
- 🌙 **Dark interface:** A modern dark design with purple accents.

## 🔒 Privacy

GestorApps is designed with privacy in mind.

- No account required.
- No registration.
- No analytics or tracking implemented.
- No advertising in the current version.
- No unnecessary special access requests at startup.

The application works locally on your Android device.

## 📱 Requirements

- Android 8.0 (API 26) or higher.
- Compatible Android device.
- Permission to query installed applications.

## 📥 Installation

1. Open the **Releases** section of this repository.
2. Download the latest APK.
3. Install it on your Android device.
4. Open GestorApps.

Android may ask you to authorize installation from the source used to download the APK.
